# Baseline Ping Pong

A dependency-free ping pong game. Play solo against the CPU or with a second player. First to seven points wins.

## Controls

- Player 1: W/S or drag on the court.
- Player 2: Up/Down arrows or drag on the right half of the court.
- Space: Pause or resume.

## Deploy on Vercel

1. Import this GitHub repository at https://vercel.com/new.
2. Set **Root Directory** to `ping-pong-game`.
3. Use the **Other** framework preset. No build command or output directory is needed.
4. Deploy.
